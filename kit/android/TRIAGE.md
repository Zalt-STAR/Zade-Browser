Keep every patch in the series, including the inert ones: later patches are written against the result of earlier ones, so dropping any makes others fail to apply. A patch to a file that is not compiled on Android costs nothing.

## What this cannot see

- Java and JNI code. Android's browser UI is Java, and several patches remove C++ features (Safe Browsing, sign-in, sync) that Java code calls into. Those failures only show up when compiling.
- Whether a target is reachable. A file can be listed for all platforms in a target that only desktop builds depend on.
- Behaviour. A patch that compiles on Android may still do nothing there, for example a setting whose only switch lives in the desktop settings page.
