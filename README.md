# Zade Browser

## Overview
Zade Browser is a Firefox-based web browser project that aims to provide a unique browsing experience while maintaining Firefox's core functionality and security features.

## Project Structure
```
/src              - Source code
/branding         - Branding assets and customization
/build            - Build scripts and configuration
/docs            - Documentation
```

## Getting Started

### Prerequisites
- Git
- Python 3.x
- Rust
- Build essentials for your platform

### Build Instructions
1. Clone the Firefox source code
2. Apply Zade customizations
3. Build the browser
